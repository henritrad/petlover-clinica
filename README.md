# 🐾 PetLover — Triagem Clínica (OAT1)

Projeto desenvolvido para a atividade **OAT1: Projeto de CRUD com Arrays** da disciplina **Desenvolvimento de APIs** (Curso de Sistemas de Informação).

## 📌 Sobre o Projeto
Aplicação web para gestão de fila de triagem clínica veterinária, implementando operações completas de **CRUD** (Create, Read, Update, Delete) utilizando uma estrutura de **Array em memória** desacoplada no motor JavaScript, com interface visual responsiva em arquivo único (`index.html`) para deploy no **GitHub Pages**.

## 🚀 Funcionalidades do CRUD
* **Create (C)**: Adição de novos pacientes à fila com validação de campos (Nome do Pet, Espécie, Tutor, Prioridade e Queixa).
* **Read (R)**: Listagem dinâmica e reativa dos pacientes registrados na fila com codificação de badges visuais por nível de prioridade (Verde/Rotina, Amarelo/Urgente, Vermelho/Crítico).
* **Update (U)**: Edição de fichas existentes com carregamento prévio dos dados no formulário de cadastro.
* **Delete (D)**: Alta/remoção de pacientes da fila com confirmação.

## 🛠️ Tecnologias Utilizadas
* HTML5 / CSS3 (Design system limpo com variáveis CSS e Grid Layout)
* JavaScript Vanilla (ES6+) com padrão de objeto de controle para manipulação de Array (`BackendArrayCRUD`)
